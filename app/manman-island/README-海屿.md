# 慢慢岛 · 海屿 1.1.0

这是原 `manman-island` 1.0.1 的原位升级包，保留原小岛、居民、成长、聊天、命名、记录本及 Hana Agent 联动。App ID 和原存储主键保持一致。

## 安装

先在原慢慢岛的存档窗口导出一份备份，然后通过 **Hana → 拓展应用 → 安装/本地 ZIP** 选择 `app-manman-island-1.1.0.zip`，按升级提示完成。不要先卸载并清除数据，也不要手动覆盖 Hana 托管目录。

进入自己的小岛后，点击岛旁的帆船。首次创建海域需要几秒；随后出现升帆、镜头拉远和离岸过程。远行后，原岛依然存在于海中，投影随实际镜头距离缩小。点击「返航」，船沿安全航线回码头，再收帆、靠岸回原岛。没有额外网络或模型调用权限。

## 海上的玩法

- 轻点水面或海图：自动开船；点击陆地会选最近的连通安全水域。
- 拖动画面：360° 转向；滚轮/双指：缩放。按钮可切平视、俯视和自动环绕。
- 按住空格或右下 `ϟ` 加速，松手后能量恢复。
- 20 群鱼在六片礁区游动。停稳在鱼群旁会出现「下竿」。咬钩后 1.4 秒内点「收竿！」；电脑也可按 F。8 种鱼含稀有石斑、金枪鱼，受礁区/水深影响。
- 12 个带光柱的漂流瓶，靠近自动拾取。一封信只收取一次。
- 「鱼与来信」打开收藏；返航把本次收获写入原记录本。
- 昼夜自动流转，一个周期约 9 分钟，也可以点昼夜按钮预览。夜间窗户、栈桥灯、灯塔光束和星星亮起。
- 声音默认关闭，点击开启。海浪、船头水声、海鸥、虫鸣及收获音效由 WebAudio 实时合成。

## 存档和升级

- 原 v2 存档不迁移、不重建。每岛新增 `slow-island.voyage.v1.<theme>` 字段，由原 Hana 保存、CAS 冲突保护与备份机制共同管理。
- 收藏、累计航程、出航次数、发现区域、能量和昼夜进度保留。每次从小岛重新出海，船会安全地从码头起航；不会把玩家强制恢复在远海。
- 上岛后居民动画继续；出海期间原岛现场暂停，海里的原岛保留出航时的居民画面。不会后台增长或虚构居民行为。
- 换岛确认会连同原岛航海收藏一起放弃。旧版 1.0.1 不认识航海字段，已有新收藏后不要直接降级；若必须回旧版，请使用升级前备份。
- 存档冲突/错误会暂停海域，可点击海上提示查看原存档窗口并导出草稿。

## 实现与边界

- Three.js 0.160.1 固定在包内，通过 ES Module + importmap 使用，无 npm/构建工具/运行时 CDN/外部模型/音频文件。
- 岛屿、船、植被、灯塔、海底和生物全部用代码构造；沙、草、海底、焦散、泡沫和光晕使用周期性程序贴图。
- 家岛特意保留原 Canvas 美术，以透明画面投影到海域中；它是可辨认的 2.5D 家岛，不是把原动物重做成 3D 模型。海中其它岛屿及物体为真实 3D 几何体。
- 这是联动海域：三座探索岛支持近岸观景和钓鱼，尚无下船登岛、采集、岛上建造。
- 夜间发光采用发光材质、叠加光晕与透明灯塔束；不是完整的屏幕空间后期泛光管线。
- 支持现代 WebGL 浏览器；Hana 内由宿主提供页面资源服务。直接双击本地 HTML 的 file:// ES 模块限制取决于浏览器，不声称所有浏览器直接双击可用。
- 宿主或页面隐藏时暂停绘制和音频；实体手机触摸、低端 GPU 长时间帧率、用户真实 Hana 升级安装仍需实机验收。
