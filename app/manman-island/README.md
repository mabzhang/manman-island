慢慢岛安装在 **Hana 的拓展应用板块**，通过卡片中心的整页入口打开。它不需要一个独立桌面程序，也不要求用户安装 Electron、Node、Python 或 npm。开发时使用的独立 Electron 仅作测试，不在交付安装包中。

原始 Canvas 画面、七种动物、1,400 条聊天条目和 108 条生活记录文案来自用户的「慢慢岛-完整交付包-20261029」。本版增加单岛归属、其他岛只读参观，以及按用户点击启动的 Agent 会话分析。

## 安装与打开

1. 将正式安装 ZIP 交给 Hana 扩展管理器的本地/上传安装入口，审阅清单和权限后确认。不要把源码 ZIP 当成安装包，也不要手工覆盖 Hana 的 apps 目录。
2. 以扩展管理器的实际安装结果为准。安装审查出现或文件已经保存，不等于 App 已启用。
3. 在卡片中心找到「慢慢岛」并点击进入。它是 Hana 内的整页应用，整页入口不能当普通卡片拖出独立窗口。
4. 日常游戏可本地运行。要使用“思考 / 工作”，请先在 Hana 中打开当前 Agent 的一个会话、选好该会话使用的模型，并授予下方列出的会话读取、模型推理及任务管理权限。

## 一次拥有一座岛

首次从七岛中选择一座，建立自己的小岛，以后默认直接进入。

点击页头“看看别的岛”可以浏览其他六座岛。参观模式只展示风景和居民的环境动画，不允许画圈创建、聊天、拖动、删除、命名、安排动作或旋转操作，也不累计或保存参观岛的成长、生活记录。原岛的进度保持不变。

参观时可以点“回我的小岛”，或者选择“创建这座小岛”。创建前必须经过弹窗：显示原岛和目标岛，提醒原居民、成长进度、生活记录和 Agent 记录将被放弃；勾选确认后才能提交。仅仅参观或取消弹窗都不会换岛。

创建成功后，新岛从初始居民开始，旧岛不再是当前可操作岛。建议换岛前导出备份。App 内保留最近一次替换前的恢复点供故障排查，但不把它当作无限历史或常规返回按钮。

若原岛还有居民在执行模型任务，不能换岛或导入备份。可以继续参观，等任务完成，或到记录本取消任务后再创建。

## 自己岛上的日常玩法

- 空地画闭合的圈迎接新居民，每岛最多 30 位；新居民随机使用 14 套柔和配色之一。
- 左击聊天；右击打开动作和命名菜单。每种动物保留 200 条聊天条目及一轮内不重复机制。
- 拖动居民调整位置，非法落点自动寻找附近空地。拖动不会当作聊天。
- 选中后按 Delete / Backspace，或点击“送它回家”。正在执行 Agent 任务的居民需要先完成或取消任务才能删除。
- 原来的吃饭、拉屎、放屁、睡觉保留。工作和思考改为真实 Agent 分析任务，不再用随机生活文案假装分析结果。
- 左右箭头、45° 按钮或空地右键拖动可以旋转；“复位”恢复默认视角。
- 成长只累计可见陪伴时间，目标最多是出生体型的 1.55 倍，体型全局上限 0.42；拥挤时受到空间约束，后台或关闭期间不补成长。
- 原触摸处理器保留：轻点聊天、约 550 毫秒长按打开菜单、拖动居民、双指旋转。390px 布局检查不等于实体手机触摸或性能认证。

## 思考与工作怎样联动 Agent

在自己的岛上右击一位居民，选择“思考”或“工作”。

### 范围与模型

- 以点击时 Hana 主会话的真实 Agent 身份作为范围，读取该 Agent **过去 7×24 小时、截至点击快照时**的会话文字。
- 包含能读取到的归档会话；归档会话在当前 Hana 版本中不可经扩展接口读取内容，会明确提示并继续分析可读会话，绝不悄悄跳过。如果 7 天范围内只剩归档会话，会直接说明并停止。
- 来源为已经保存、可通过官方接口读取的 user / assistant 正文。模型内部推理、工具结果、图片字节不发送；图片和附件未解析会明确提示。发送失败的空正文不能凭空恢复。
- 不设“只读前几个会话”或“只取前半段”的静默上限。较长内容会完整分段处理，再合并摘要；读取失败、结构无法识别或模型限额错误会明确停止，不能声称已覆盖未读取的内容。
- 使用**点击入口所对应会话当前选定的模型**，从宿主公开目录精确匹配 provider / model。不会自行选择另一个模型，不读取或保存 API Key，也不修改会话模型设置。
- 这是受限的会话分析任务：不向原聊天发消息，不编辑用户文档，不执行该 Agent 的工具或对外动作。

### 思考

概括近期在推进的事情，提出会话中尚未明确讨论或验证的角度，包括遗漏的假设、潜在机会、跨话题关联和替代做法，并给出可以验证的下一步。不假装知道用户心里“绝对没想过什么”。

### 工作

以熟人损友式的直言挑错：指出逻辑漏洞、未核实的条件、前后矛盾和执行缺口。可以尖锐吐槽，但要紧跟证据、后果和改法；不能只做人身评价，不能凭空编问题，也不能把助理提出的错误甩给用户。

### 任务过程

一座岛同时只跑一个 Agent 任务，防止重复点击造成并发费用。居民会保持对应工作/思考姿态；记录本显示读会话、分段分析、合并、完成、失败或取消状态。分析完成后立即出现在记录本的“思考与工作”区域，并带来源编号、会话入口、时间范围及模型已报告用量。

可以在记录本取消。页面隐藏时游戏动画暂停，已启动的后台分析可继续；关闭页面后重新打开可读取已保存的结果。Hana 或 App 重启导致的未完成任务标为中断，不会自动重新花费模型用量。

模型返回空正文、半截输出、无效来源编号或连接错误都会显示失败，不拿预写台词替代。推理过程不显示、不存入笔记。记录本保存成功和后台任务结束回执分别处理，回执未确认时有提示。

## 两类记录分开显示

**生活小事**沿用原频率：全岛每 5 分钟随机 1–4 条，并按 300 秒除以条数均匀写入，最多保留最近 200 条。只有页面可见且岛上有人时累计，不补记离线时间。

**Agent 思考 / 工作**由明确点击发起，真实完成后立即写入，不被生活小事的随机计时器延后，也不会被生活记录的 200 条滚动上限删掉。Agent 记录达到容量边界会拒绝新任务并提醒备份，不静默清除旧结果。

## 存档、备份与冲突保护

页头“存档”提供状态查看、立即保存、导出 JSON 备份和恢复备份。自动保存复用事件保存与约 5 秒的游戏保存周期；同一批居民和生活记录修改合并发送，宿主确认后才显示已保存。

业务数据存入 App 自己的 `sdk.storage.global`，不依赖 iframe 地址或浏览器 localStorage。游戏进度和 Agent 记录在一个宿主原子存储对象中维护；后台笔记更新不会触发游戏版本冲突，也不会被下一次游戏自动保存覆盖。

多窗口写入采用版本检查。落后的窗口会停止写入并提示，不做“最后保存者无条件覆盖”。网络丢失确认后重用原变更编号，避免重复提交。关闭前想确保最近操作已落盘，可点“立即保存”等待确认；崩溃、断电和立即销毁页面仍不能保证零秒数据损失。

备份采用联动版 v2 格式，包含当前岛进度及本窗口已载入的 Agent 记录；未载入匹配记录时会明确提醒。恢复前先检查格式，再要求用户确认替换。备份里的未完成任务不会自动续跑。整体备份上限 8 MiB，游戏数据上限 2 MiB，Agent 记录上限 4 MiB。

原单 HTML 所在浏览器的个人存档没有包含在原始交付 ZIP 中，也不会自动迁入 Hana；原文件不被改动。不要直接修改 Hana 底层存档文件。

## 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `app/sessions.read` | 获取主会话所属 Agent，读取其最近7天文字，并打开用户点击的来源会话 |
| `app/models.infer` | 通过 Hana 已配置的模型通道执行分析，可能产生费用 |
| `app/tasks.manage` | 注册、更新和取消这个 App 自己的后台任务 |
| `app/resources.write` | 用户点“导出备份”后，由 Hana 选择目标并保存文件 |

权限由 Hana 的安装审查和应用权限页管理。日常玩法不需要读取会话或调用模型。会话读取授权在平台层面属于较宽的读权限，本版代码再按参考会话的 Agent 身份过滤，并非声称平台提供了额外的按 Agent 操作系统隔离。

App 不自设外部服务地址；**AI 联动仍会把选定范围的文字交给你在 Hana 中配置的模型提供方处理**，是否联网及计费取决于该配置。它没有原会话写入、会话启动回合、系统命令、任意文件读取或 Provider 凭据读取权限。

## 技术与验证

- `index.js`：官方 `defineApp` 入口，注册自有保存和分析路由。
- `save-repository.js`：原子存储队列、单岛约束、确认换岛、版本冲突与幂等重试。
- `analysis-source.js`：官方会话接口、当前分支及7天文字窗口、完整分片。
- `analysis-engine.js`：模型精确匹配、分段/合并、任务取消、来源校验和结果记录。
- `ui/island.html`：原有画面、文案和游戏逻辑，定点增加归属和联动接口。
- `ui/bridge.js`：官方 UI SDK、存档入口、只读参观、确认弹窗及 Agent 记录展示。
- `ui/save-client.js` / `save-format.js`：保存客户端与共享校验。
- `sdk/`：官方 Creator 复制的自包含 SDK；无运行时 npm 安装。

正式安装 ZIP 由 Hana 官方打包器生成，并应对最终归档再跑静态和隔离 smoke 校验。组件测试使用真实产品代码，但 SDK 会话和模型边界替换为测试数据，不能冒充生产环境的真实模型成功记录。具体通过结果和未测项见随附验收说明。
