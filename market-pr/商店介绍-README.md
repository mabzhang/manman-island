# 慢慢岛

一座住进 Hana 的小岛。挑一座岛慢慢待着，画圈迎接软乎乎的居民，看它们闲逛、长大、陪你发呆；也可以点开保育员记录本，留住每天的小事。

慢慢岛 Hana 版新增两个能力：

- **一次拥有一座岛**：其他六座岛可以只读参观，创建新岛前会明确确认放弃旧岛。
- **居民帮你看会话**：点击居民的「思考」，它会回顾本 Agent 最近 7 天的文字会话，补上你可能漏掉的角度；点击「工作」，它像个敢说重话的朋友，直接指出哪里想漏了、哪里还没核实。结果和依据的会话都写进记录本，可以点回去核对。

## 权限说明

- 读取会话、模型推理：只有你点击「思考 / 工作」时才使用，可能产生模型用量；图片和附件不会发送给模型。
- 任务管理：运行和取消分析任务。
- 写入资源：仅在导出备份文件时使用。

全部数据保存在本机 Hana 的工作室内，不上传外部分析服务；模型调用走你在 Hana 中配置的模型。

## 使用提示

- 首次进入选择一座岛，之后直接回到你的岛。
- 使用「思考 / 工作」前，请先在 Hana 打开当前 Agent 的一个会话，并确认该会话使用的模型。
- 右上角「存档」可以导出 JSON 备份；换岛、恢复备份都有明确确认。

慢慢岛延续原单文件版本：1400 条居民聊天、108 条保育员生活记录、纯 Canvas 绘制，不依赖外部图片、字体或库。
