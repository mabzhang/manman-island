# 慢慢岛 · 海屿 1.1.0 升级安装说明

## 安装这个文件

`app-manman-island-1.1.0.zip` 是 Hana 可安装拓展 ZIP。`慢慢岛-海屿-1.1.0-源码与验证.zip` 是开发交接资料，不用于 Hana 安装。

1. 在原来的慢慢岛中，打开存档窗口，导出一份升级前备份。
2. 在 Hana 的拓展应用安装入口选择 `app-manman-island-1.1.0.zip`，按界面完成升级。不要先卸载并清除旧应用数据。
3. 打开自己的小岛，点击岸边「乘船出海」。第一次初始化海域需要几秒，随后升帆、镜头拉远、连续离岸。
4. 轻点海面/海图开船，拖动转视角，滚轮或双指缩放。右下 `ϟ` / 空格加速。停稳在鱼群旁下竿，咬钩后 1.4 秒内收竿。靠近漂流瓶自动拾取。
5. 点击「返航」，船会走安全航线回码头，靠岸后原岛继续运行；本次收获会写进记录本。

## 这一版的联动

原 App ID `manman-island`、存储主键、居民、成长、命名、记录本、Agent 功能保留。海上收藏与原存档一起保存和备份。返航有航行过程，不是点按钮就换回页面。

家岛保留原有 Canvas 美术，作为海中的 2.5D 家岛，随实际视距缩小；出航期间居民现场暂停。海中另外三岛和船、灯塔、椰树、生物等是代码构造的 3D 场景。探索岛目前支持近岸观景和钓鱼，尚无下船登岛。

水面、水深寻路、昼夜、20 群鱼、海龟海鸥、12 封漂流来信、8 种鱼图鉴、程序合成声音、手机竖屏布局均已接入。声音默认关闭，可手动开启。

## 兼容与验证

清单最低版本沿用原包的 `1.3.6-beta`；官方隔离加载验证使用本机 Hana `1.5.7-beta` 工具。旧最低版本没有重新实机测试。

验证结果见《测试与兼容报告》。本次没有在用户真实 Hana 中执行安装，没有读取真实聊天或调用收费模型。实体手机、低端 GPU 和长时间运行表现需要实机验收。

新收藏写入后，旧 1.0.1 不认识航海字段。需要回退时，使用升级前备份，不要直接拿带新收藏的存档降级。

## 文件用途

- 安装 ZIP：直接交给 Hana。
- 同名 `.entry.json`：官方打包工具生成的分发元信息；本地 ZIP 安装通常不需要它，也没有替你发布市场。
- 源码与验证 ZIP：源码、构建复制脚本、测试、原包对照清单、差异、官方校验结果和真实界面截图。
- 《源码审阅与升级设计说明》：资料理解、原功能链路、实现结构和范围说明。
