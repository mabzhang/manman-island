## 海域验证覆盖

1. 点击原岛小船进入连续离岸过程，原居民现场暂停；4 岛、6 礁、20 群鱼及实例数量检查。
2. 行驶到首个漂流瓶，自动拾取并通过原 repository 保存。
3. 远航后家岛屏幕投影宽度减少。
4. 鱼群旁下竿、咬钩后及时收获、错过窗口逃鱼、8 格图鉴。
5. 实际鼠标拖动、Chromium CDP 双指触摸缩放、空格加速消耗能量、WebAudio 创建/播放、收藏弹窗暂停/恢复声音。
6. 白天、黄昏、日落、月夜、黎明五档预览断言；390×844 无横向溢出，返航、海图、钓鱼和加速控件在边界内。
7. 灯塔岛外目标实际抵达（误差小于 5 米），观察 3D 岛景。
8. 宿主隐藏时海域 clock 不增长，恢复后继续。
9. Three 场景几何属性有限值检查，renderer console errors 为空。
10. 沿安全航路返航、靠岸、恢复原游戏，把航海记录写入原笔记，并重载保留收藏。

海域长航行在测试服务器中注入时间推进，以较短时间验证状态链路；测试钓鱼位置也使用夹具。正式代码不包含这些方法。导航网格、路径安全和连通终点另外由单元测试验证。不会把这组测试描述为完整真人长时间游玩。

## 官方校验的通用警告

`DYNAMIC_DEPENDENCIES_NOT_PROVEN` 表示静态扫描只跟踪声明的 HTML/CSS，不能证明运行时动态 import。官方 smoke 已验证宿主启动与 SDK；海域懒加载和 Three 场景由另 11 项浏览器交互验证。安装 ZIP 中的海域模块和本次被测源码一致。

## 运行环境与未验证项

- 单元/构建使用本机 Node；官方校验使用 Hana Server 1.5.7-beta 的 Node 26.12.1。
- 浏览器组件测试使用已有独立 Electron 45.1.0，fixture SDK；官方 smoke 使用官方隔离宿主。
- manifest 最低版本沿用 1.3.6-beta，未在该旧宿主版本实测。
- 没有在用户真实 Hana 中安装升级或覆盖存档；真实账户的安装界面和授权仍需安装时验收。
- 手机验证为 390×844 Chromium 布局与合成触摸事件，未在实体手机运行，也未作低端 GPU 长时间性能/功耗测试。
- 音频验证为 WebAudio 上下文和生命周期工作，无异常；未做扬声器主观听感验收。
- 原岛采用 2.5D 当前画面投影；其它岛为 3D。没有探索岛下船功能，夜间光晕不是完整后期 bloom。
- 不保证 file:// 双击 HTML 在所有浏览器可用；正式 Hana 通过本地资源服务加载 ES Module。
